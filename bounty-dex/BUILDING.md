# BOUNTY Dex — сборки

## Получить APK для Android
1. Откройте вкладку **Actions** репозитория.
2. Выберите **Build BOUNTY Dex Android APK**.
3. Дождитесь зелёной галочки у запуска workflow.
4. Внизу страницы запуска скачайте artifact **BOUNTY-Dex-Android-APK** и распакуйте ZIP — внутри будет APK.

## Получить приложение для Windows 10/11
1. В **Actions** выберите **Build BOUNTY Dex for Windows**.
2. Дождитесь завершения и скачайте artifact **BOUNTY-Dex-Windows**.
3. Распакуйте ZIP и запустите `BOUNTY-Dex.exe`.

## Размер
Размер около 50 МБ — ориентир, а не гарантированное значение. Windows-сборка включает Qt/PySide6 и может оказаться больше; APK обычно существенно меньше. Точный размер станет известен после первой сборки. Не включайте ADB/scrcpy в APK: это инструменты для Windows-хоста, их нужно положить в `windows/tools/` согласно README.

## Важно
Android companion 0.1.0 — установочный помощник с инструкциями. Само зеркалирование и управление экраном выполняются на ПК через ADB + scrcpy. Для USB нужно разрешить отладку по USB. Для Wi‑Fi на новых версиях Android может понадобиться первоначальное сопряжение через «Беспроводную отладку» (код сопряжения и порт).
